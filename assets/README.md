# Portada del repositorio

Diagramas SVG adaptados a desktop y móvil; fondos oscuros, sin scripts ni recursos remotos. El contenido también está explicado en el README en texto.

Tipografía: Space Grotesk de Florian Karsten, obtenida del repositorio oficial Google Fonts. Los glifos están convertidos a trazados para que GitHub los renderice sin depender de fuentes instaladas. Licencia SIL Open Font License 1.1 incluida en `OFL-SpaceGrotesk.txt`.
