# Contribuir

1. Creá una rama desde `main`.
2. Usá exclusivamente fixtures sintéticos.
3. Ejecutá `npm test` y `npm run check`.
4. No agregues llamadas productivas en tests.
5. Toda capacidad de escritura fiscal debe incluir un guardrail explícito y una
   prueba que demuestre el bloqueo por defecto.

Los cambios de tablas, vencimientos o reglas deben citar una fuente oficial y
mantener la vigencia versionada.
